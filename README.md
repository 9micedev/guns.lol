# guns.lol

Static assets and repository metadata for a small web/profile project.

## Repository Contents

- `icons8-*.png` - technology and UI icons used by the project.
- `.gitignore` - local development and build-output ignore rules.
- `LICENSE` - Apache 2.0 license.

## Development Notes

- Keep source files and generated build output separate.
- Do not commit local credentials, cookies, tokens, or `.env` files.
- Add setup and deployment instructions before publishing runnable code.
- Keep asset names clear so they are easy to reuse later.

## Status

This repository is currently a lightweight asset and metadata repository. Add a project structure such as `src/`, `public/`, or `docs/` when active development starts.
